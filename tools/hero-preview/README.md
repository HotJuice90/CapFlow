# Офлайн-превью hero-поля

Порт шейдера `src/components/hero/shader.ts` на JS + свой PNG-энкодер (без
зависимостей). Нужен, чтобы подбирать композицию поля, НЕ гоняя цикл
«сборка → релиз → скриншот с телефона»: одна итерация занимает секунду
вместо пяти минут.

```
node tools/hero-preview/hero.js out.png [intensity] [warmth]
```

Рисует три кадра (t = 0 / 9 / 21 с) рядом, поверх фонового градиента экрана,
с двумя горизонтальными маркерами — строка «Сегодня принесёт» (y=178) и
строка суммы (y=218). Маркеры показывают, где именно должна быть максимальная
плотность.

Порт РУЧНОЙ и синхронизируется руками: поменял шейдер — поменяй и здесь,
иначе превью начнёт врать. Числа подбираются тут, потом переносятся в SkSL.
